Claude Code のスラッシュコマンドは、公式の一覧に 110 件以上あります。全部覚える必要はありません。実際に毎日触るのは 6 つ程度で、残りは「困ったときに引く」ものです。この記事では、公式ドキュメントの一覧を使用頻度の順に組み替えて、それぞれの意味と使いどころを整理します。

最初に 1 つ、つまずきやすい点があります。**組み込みコマンドの一覧ページは移動しています。**

> **要点**
> この記事で分かること
>
> - 公式の一覧がどこにあり、表の `<arg>` と `[arg]` をどう読むのか
> - 毎日のセッションで実際に使う 6 つのコマンドと、その引数
> - Skill・Workflow の印が付いたコマンドは何が違うのか、なぜ人によって表示が変わるのか

## まとめ

- 組み込みコマンドの公式一覧は `/docs/en/commands`。`/docs/en/slash-commands` はスキルのページに変わっている
- 表は Command と Purpose の 2 列。`<arg>` は必須、`[arg]` は省略可
- 毎日使うのは `/clear`、`/compact`、`/context`、`/model`、`/resume`、`/rewind` の 6 つ
- Skill は Claude に渡されるプロンプト、Workflow は複数のサブエージェントに分散する処理。どちらも呼んだときだけ動く
- 一覧にあっても、プラットフォーム・プラン・環境によって表示されないコマンドがある。手元の一覧は `/help` で確認する
