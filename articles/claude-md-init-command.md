Claude Code を新しいリポジトリで使い始めるとき、最初に打つコマンドが `/init` です。実行すると Claude がコードベースを調べて `CLAUDE.md` を書いてくれますが、生成された内容をそのまま放置すると、長すぎて指示が効かなくなることがあります。

結論として、`/init` の出力は「たたき台」です。コードを読めば分かる内容は削り、Claude が推測できないコマンドや規約を書き足してから、`/context` で読み込みを確認します。

> **要点**
> この記事で分かること
>
> - `/init` が調べる対象と、生成される `CLAUDE.md` に入る内容
> - 既存の `CLAUDE.md` や他ツールの設定ファイルがあるときの挙動
> - 生成後に削る内容・書き足す内容と、読み込みの確認方法

## まとめ

- `/init` はコードベースを分析して、ビルドコマンド・テスト手順・規約を書いた `CLAUDE.md` を生成する。既存ファイルは上書きせず改善案を出す
- `CLAUDE_CODE_NEW_INIT=1` で、スキルやフックも含めた対話型の初期化になる
- 生成後は、ディレクトリ構成や依存一覧などコードから分かる内容を削る。目安は 200 行未満
- 推測できないコマンド、既定と異なる規約、環境の癖、落とし穴を具体的に書き足す
- `/context` の Memory files で読み込みを確認し、長くなったら `/doctor` の削減案を使う
