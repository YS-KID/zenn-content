Claude Code を使い始めるとき、最初に決めるのが支払い方法です。選択肢はサブスクリプション(Pro / Max / Team / Enterprise)と API 従量課金の 2 系統あり、料金の考え方も上限の扱いも違います。

結論を先に書くと、**毎日まとまった時間使うならサブスクリプション、CI や自動化で使うなら API キー** です。公式ドキュメントは企業導入の平均を「開発者 1 人あたり月 150〜250 ドル」としており、この水準で使うなら定額のほうが安く収まります。

この記事の金額は **2026 年 10 月 5 日時点** に公式ページで確認した値です。料金は改定されるため、契約前に必ず公式ページで最新の値を確認してください。

> **要点**
> この記事で分かること
>
> - Claude Code が使えるプランと、使えないプラン
> - サブスクリプションと API 従量課金の料金と、上限の違い
> - 上限に達したときの 3 つの選択肢と、使い方別の選び方

## まとめ

- Claude Code は有料プランすべてに含まれ、無料プランでは使えない。上限はプランの他の用途と共有する
- 2026 年 10 月 5 日時点で、Pro は年払い月 $17・月払い $20、Max は月 $100 から、Team Standard は 1 席年払い月 $20
- API 従量課金は上限なしの従量制。Opus 5.5 が $4/$20、Sonnet 5.5 が $2/$10 per MTok
- 上限に達したら「待つ」「上位プランに移る」「使用クレジットを標準 API レートで使う」の 3 択
- 月 150〜250 ドル相当を使うならサブスクリプション、週に数回か自動化中心なら API が向く
