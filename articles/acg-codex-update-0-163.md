Codex CLI の v0.163.0 は、5 日前の v0.161.0 で変わったばかりの **Daybreak の有効化方法を元に戻す**リリースです。あわせて設定画面と対話中の操作、ネットワークプロキシのセキュリティ修正が入りました。

結論として、この 1 本で確認すべきことは 2 つです。Daybreak を明示的に無効化していたなら現在の状態を確認すること、そしてサンドボックスでネットワークを絞っているなら 0.163.0 に上げることです。

> **要点**
> この記事で分かること
>
> - Daybreak が対象アカウントの既定に戻ったこと
> - `/config` の横断検索と、応答中にフォローアップを送れるようになったこと
> - ネットワークプロキシに入った 3 つの修正

## まとめ

- v0.163.0 で Daybreak が対象アカウントの既定に戻った。`cli_daybreak` の明示的な指定は不要になった
- `/config` で設定をカテゴリ横断で検索でき、再起動が必要な変更が分かるようになった
- 応答中にフォローアップを送って軌道修正でき、中断すると Code Mode のセルも止まる
- ネットワークプロキシが DNS 参照の前に権限を確認し、重複した `Host` ヘッダーを拒否するようになった
- `/config`・`/keymap`・`/daemon` と、引退したシェルのフラグ名は公式ドキュメントでは確認できなかった
