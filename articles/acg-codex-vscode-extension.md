Codex は CLI だけでなく、VS Code のサイドパネルからも使えます。拡張機能を入れると、開いているワークスペースに対して指示を出し、変更差分をエディタ上で確認しながら進められます。ローカルでの作業に加えて、クラウド版の Codex にタスクを委任することもできます。

この記事では、拡張機能の導入から、指示の出し方、ローカル・クラウドの使い分け、承認設定の変更までをまとめます。

> **要点**
> この記事で分かること
>
> - 拡張機能のインストールとサインイン
> - サイドパネルからの指示、差分確認、承認の流れ
> - ローカル実行とクラウド実行の使い分け

## まとめ

- Marketplace から Codex 拡張を入れ、Codex のアイコン(なければ **Codex: Open Codex Sidebar**)でサイドパネルを開く
- 対象は VS Code・Cursor・Windsurf。エディタで開いている内容が文脈として入った状態でチャットが始まる
- 対話的な作業はローカル、時間のかかるタスクは Codex web に委任する
- `@` 参照やパネル内のモデル切り替えなど、個々の操作は公式 IDE ページでは確認できなかった
